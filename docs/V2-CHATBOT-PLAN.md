# ver2.0 計画書 — 企業別AIチャットボット

v1.0（収集→AI要約/採点/ピックアップ→PWA）は完成。ver2.0 の第1弾として
**収集済みデータを使った「企業別AIチャットボット」** を実装する。
本書は議論（壁打ち）で固めた方針。次回はこの計画に沿って実装着手する。

---

## 1. コンセプト
収集済みのニュース（Notion）を文脈として、企業について自然言語で質問できるチャット。
例:「IONQ、最近どう？」「Anthropicの資金調達の規模は？」「X-energyとIHIの提携は？」

## 2. 確定方針（議論の結論）
| 項目 | 決定 |
|------|------|
| 公開範囲 | **自分専用**（`ADMIN_PASSWORD` で解錠。公開・乱用対策は初版では不要） |
| 検索方式 | **ハイブリッドRAG**：質問語で記事検索（②）→ ヒットが少なければ最近＋重要度上位で補完（①） |
| LLM | Groq（既存）。チャットは**軽量モデル** `llama-3.1-8b-instant` を既定（`GROQ_CHAT_MODEL` で上書き可）。枠を伸ばすため |
| 消費管理 | **既存の使用量ゲージ＋ロックに統合**。Groqロック中はチャットも停止（生記事提示にフォールバック） |
| 回答 | **参照した記事リンクを必ず添付**（ハルシネーション抑制・信頼性） |
| 会話 | まず**単発Q&A**。マルチターンは様子見で後追加 |
| スコープ | 企業ごと（選んだ銘柄について聞く）。「全企業」モードは任意で検討 |

## 3. API消費の試算
- 1メッセージ = Groq **1回**（入力 ~1,500トークン[システム+関連記事要約数件+質問] / 出力 ~300）
- 8b-instant 採用で 70b より大幅に省トークン・高速・高レート上限
- キーワード検索（②）はNotion/ローカル絞り込みのみ＝**LLM不使用＝ほぼ無料**
- 既存の日次上限ロックで暴走防止済み

## 4. アーキテクチャ
```
[PWA /chat（パスワード解錠）]
  → POST /api/chat { ticker, question }（admin認証必須）
      1. 取得: storage.list({ticker, limit:60}) から
         ②質問語で本文/タイトルを絞り込み → 不足なら①最近+重要度上位で補完（最大8件）
      2. プロンプト構築（関連記事の要約＋タイトル＋日付）
      3. Groq（chatモデル）で回答生成（groqComplete を再利用/拡張）
      4. usage 記録（既存 addUsage）。Groqロック中は503で停止
  → 返却 { answer, sources: [{title,url,importance}] }
```

## 6. 段階リリース
- **PR-1**: バックエンド（retrieve + answer + /api/chat）＋最小UI
- **PR-2**: UX磨き（履歴表示・ローディング・空状態・参照カード）
- **後追い候補**: マルチターン会話 / 全企業横断モード / 回答キャッシュ

## 7. 非対象（今回やらない）
- 公開チャット（乱用対策・レート制限が必要なため）
- ベクトル検索RAG（埋め込みAPIが別途必要。①②で十分なら不要）
- 株価データ連携・通知系（ver2.0 の別テーマとして後日）
